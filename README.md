# Gift Quest 🎁

Interactive birthday / memory quest built with Laravel.

## Features

- Multi-level interactive story
- Question-based progression
- Memory gallery
- Mini-game integration
- Easily customizable for any person

## Tech Stack

- Laravel
- Blade
- Tailwind CSS
- MySQL

## Installation

```bash
git clone repo_url
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
